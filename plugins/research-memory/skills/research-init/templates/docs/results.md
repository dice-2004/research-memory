# 結果の索引

> 実験を終えるたびに1行足す。数値を MEMORY.md・報告・発表・卒論で使うときは、まずここで探し、原本（最終の表）のファイルで値を確かめる。
> ここの数値は最終の表からの写し（計算し直さない）。食い違ったら原本が正しい。

## 列の意味

| 列 | 書くこと |
|---|---|
| 実験 | 実験IDの中の個々の実行（例: `01`、`K=4`）。1回だけなら実験IDそのもの |
| 最終の表 | 人が見る表（CSV・MD）のパス。実験IDのフォルダからの相対パス |
| 主な数値 | 主指標と副指標の値（集計方法も。例: 5カテゴリの単純平均） |
| 比較相手の出典 | 並べた比較相手の値と、その出典（論文の表番号・ノートへのリンク・別の実験ID） |
| 確認 | 終了コード・出力の監査・実行中のコード変更の有無など、数値を信じてよいかの確認の結果 |
| ログ | 実行と確認を書いたログの日付と時刻 |

## <exp-NNN>（`<結果の置き場>/exp-NNN_<名前>/`）<目的を一言で>

| 実験 | 最終の表 | 主な数値 | 比較相手の出典 | 確認 | ログ |
|---|---|---|---|---|---|
| <01> | <`…/summary.csv`> | <例: 主指標 0.5672（MACRO）> | <例: 0.5699（[著者 年](papers/citekey.md) 表2）> | <例: exit=0、監査エラー 0 件、実行中のコード変更なし> | <`logs/YYYY-MM-DD.md` の HH:MM> |
