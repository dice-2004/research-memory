# 実験の実行手順

> 実験を1回行うときの手順の正本。AGENTS.md §3 や個人ノートはここを指す。**手順を変えるときはここだけを書き換える。**
> `<...>` を埋めて使う。項目が当てはまらなければ消してよい。

**手順が分からないとき**は、実際にこの手順で行った実験と同じようにする。`git log --oneline --grep "exp-NNN"` で実行した順番、実験フォルダの実行記録で実際のコマンド、`docs/experiments.md` とその日のログで確かめたことが分かる。手本にする実験: `<例: exp-001>`

## 0. 初回だけ: 環境を作る

```bash
<例: docker compose build <本番用のサービス名>>
```

- 本番の数値を出す環境: `<例: CPU 版の torch x.y、Python 3.10、スレッド数固定>`
- 開発用の環境: `<例: GPU 版。本番の数値には使わない>`
- 依存パッケージの版の固定: `<例: requirements.txt>`。変えたら環境を作り直す。

## 1. 始める前に

- [ ] **ブランチと実験IDを決める**。命名は `CONTRIBUTING.md`（番号は既存の最大 + 1）。実験ID＝ブランチ番号で、結果は `<結果の置き場>/exp-NNN_<名前>/` に置く。
  - **変更を加えてやり直す**（コード・設定・手順・データのどれかを変える）なら、新しいブランチと実験IDにする。結果は新しい `exp-NNN_<名前>/` に置き、前の結果は残る。
  - 変更を加えずに続けて実行する（再現の一連の実行など）なら、同じブランチ・同じ実験IDのまま。
- [ ] **`docs/experiments.md` に1行足す**（目的・状態「進行中」・結果の場所）。
- [ ] **実験の順番と、前の結果を使うか**を確かめる。前の実験の結果（特徴・保存したモデルなど）を読む実験なら、それが Git 管理外でもディスクから消さない。
- [ ] 変更を加えずに同じ実験をやり直すとき（失敗のやり直しなど）は、前回の結果が消えたり上書きされたりしないかを確かめ、上書きになるなら先にユーザーに確認する。
- [ ] 長い実行（目安1時間超）なら、先に確認を取る。
- [ ] 結果に関わるコード（`<例: src・scripts・configs>`）に未コミットの変更があれば、実行の前にユーザーにコミットを依頼する（AI は依頼されるまでコミットしない。未コミットでも記録は残すが、追いにくい）。

## 2. 実行する

```bash
<実行コマンド>
```

- 用意されたスクリプトはそのまま動かす。`time`・`tee` など自分で足したものは付けない（実行記録は終わった後に残す）。
- ターミナルを占有したくないとき（Claude に実行させるときなど）は、裏で動かして終わるのを待つ（`<例: docker compose run -d --name … と docker wait …>`）。
- **実行中は結果に関わるコードを変えない**。docs・logs・個人ノートは変えてよい。

## 3. 終わった後

```bash
<例: 実行記録を残すスクリプト>
```

- [ ] 実行記録を残す: コマンド・環境（イメージ・環境変数）・コミット・未コミットの変更（差分）・主要ライブラリの版・開始と終了の時刻・終了コード。
- [ ] 終了コードが 0 かを確かめる。
- [ ] 実行中にコードが変わっていないかを確かめる。変わっていたらログに書いて報告する。
- [ ] **数値を見る前に**、結果が正しく作られたかの確認（`<例: 出力ファイルの監査・件数の確認>`）でエラーがないかを確かめる。エラーがあれば数値に意味がない。
- [ ] 結果を比較相手の値（`<例: 論文の表・指導教員の値>`）と並べる。主指標は `<指標>`。

## 4. 記録する

- [ ] `logs/YYYY-MM-DD.md` に実験のブロック（実験ID・設定・結果・考察・次にやること）を足す。失敗した実験も残す。
- [ ] **`docs/results.md` に1行足す**（最終の表のパス・主な数値・比較相手の出典・確認の結果・ログ）。値は最終の表から写すだけで、計算し直さない。
- [ ] `docs/experiments.md` の行（状態・結論）を更新する。
- [ ] `MEMORY.md` の「現在の実験状態」の更新を提案する（ユーザー承認制）。
- [ ] コミットする（依頼があってから）。Git で管理するのは `<例: 結果のうち CSV・MD・JSON と実行記録>`（大きなファイルは管理外）。
